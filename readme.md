# Loan Application Drop-Off & Approval Analysis Using SQL

## Project Overview
This project analyzes fictional loan application data using MySQL to understand application outcomes, KYC completion, approval rates, and customer segments.

## Objective
- Calculate overall loan approval rate.
- Identify KYC drop-off patterns.
- Compare approval performance across acquisition sources.
- Analyze approval outcomes by credit-score bands.
- Identify areas that need further investigation.

## Tools Used
- MySQL
- MySQL Workbench

## SQL Concepts
- SELECT, WHERE, ORDER BY
- INNER JOIN
- GROUP BY and HAVING
- Aggregate functions
- CASE WHEN
- Percentage calculations
- Common Table Expressions (CTEs)
- Window functions: ROW_NUMBER()
- Date-based aggregation

## Key Findings
- Overall approval rate: 50% (6 of 12 applications).
- KYC drop-off rate: 16.67% (2 of 12 applications).
- Campaign KYC drop-off rate: 66.67% (2 of 3 applications).
- Referral approval rate: 75% (3 of 4 applications).

## Limitations
The dataset is fictional and small. Findings are for SQL practice and do not establish causal reasons for loan rejection or customer drop-off.
